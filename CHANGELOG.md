# Changelog - Crispy-Master-Menu v2.0
This updated version of Crispy-Master-Menu features new characteristics.

---

## [2.0] - Official Release
### Added

1. *New navigation system for the launcher, aiming for the closest possible resemblance to the one in the official release of DOOM + DOOM II..*

2. *Custom WADs that are found are now remembered in the listbox; a new button called "Clear list" has also been added, allowing you to clear the listbox if you wish to start a new list.

3. Launcher weight optimization, reducing the size from 3.64 MB to 3.16 MB.

4. New parameters have been added, such as "Mirror Levels," "Double Ammo," and "Flip Weapons."

5. Support for Crispy Heretic, Hexen, and Strife.

6. Custom WADs and WAD Combining: Cleanly load secondary files (.wad, .deh, Heretic's .hhe patches, Hexen's .hex patches and strife's .seh patches ), perfect for mixing maps with custom texture. To select more than one custom WAD, hold down the CTRL key. Additionally, the launcher now automatically chooses the correct IWAD and map for any selected WAD (starting from the first map for multi-level campaigns, or jumping straight to the correct level for single-map mods).
